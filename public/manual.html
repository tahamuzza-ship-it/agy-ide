📖 Manual de uso de AGY IDE

Guía rápida para hablar con AGY, escribirle, trabajar con código y enviar misiones seguras a PC1.

Regla sencilla: una orden dirigida a PC1 se envía inmediatamente. Una pregunta por tareas pendientes solo consulta la lista.
EN 30 SEGUNDOS

Lo esencial

  1. Elige el equipo destino: PC1, PC2 o Cualquiera.
  2. Escribe una instrucción en el chat o toca el micrófono.
  3. Una orden para PC1 crea una misión; una consulta de pendientes solo muestra la lista.
BOTÓN DE SEGURIDAD

Detener una ejecución

Para detener algo que corre en una terminal, usa Ctrl+C. Las misiones enviadas aparecen en Entrada PC1 para que puedas ver su estado.

⌨️ Usar AGY por texto

Escribe en la caja de chat y pulsa la flecha ➤ para enviarlo. Puedes pedir explicaciones, pasos o ayuda con un archivo.

“Explícame qué hace este código antes de cambiarlo.”
“Dame los pasos para comprobar si este script está funcionando.”
“Ayúdame a corregir este error sin borrar mi trabajo.”

El dictado normal también deja el texto en la caja de chat: revísalo y envíalo manualmente cuando estés conforme.

🎤 Usar AGY por voz

  1. Toca el botón 🎤 junto al chat.
  2. Habla con normalidad.
  3. Para dictado normal, revisa el texto que quedó escrito y envíalo con ➤.

Órdenes de voz del Buzón 1

Para enviar una tarea, habla con naturalidad. Estas órdenes crean la misión inmediatamente:

“AGY, dile a PC1 que revise el disco.”
“Misión para PC1: revisa el disco.”
“Manda a PC1 a revisar el disco.”
“PC1, revisa el disco.”

AGY responde: “Entendido, orden enviada a PC1.”

Para ver pendientes, pregunta:

“¿Qué tareas tiene PC1 pendientes?”
“Muéstrame las misiones pendientes de PC1.”
“Consulta el Buzón 1.”

📬 Buzón 1: misiones para PC1

Solo hay dos cosas que necesitas saber:

1. MANDAR UNA MISIÓN A PC1

Habla como una persona normal
“AGY, dile a PC1 que revise la cámara.”
“Misión para PC1: revisar el disco.”
“Manda a PC1 a comprobar el listener.”
“PC1, revisa la memoria.”

Resultado: AGY responde “Entendido, orden enviada a PC1.” y la tarea queda en Entrada PC1 como PENDIENTE.

2. VER MISIONES PENDIENTES DE PC1

Di o escribe
“¿Qué tareas tiene PC1 pendientes?”
También puedes decir
“Muéstrame las misiones pendientes de PC1.”
“Consulta el Buzón 1.”

Resultado: ves la lista real de tareas de Entrada PC1, con su estado: PENDIENTE, EN_PROCESO, COMPLETADA o ERROR.

Regla fácil: una orden crea una tarea; una pregunta por pendientes solo muestra la lista.

💻 Trabajar con código

Editor

El panel izquierdo es el editor. Abre o selecciona archivos desde 📁 ARCHIVOS, haz tus cambios y revisa antes de ejecutar.

Ejecutar

El botón ▶ EJECUTAR corre el contenido actual para el equipo seleccionado. El resultado aparece en OUTPUT — AGY.

Antes de ejecutar: confirma que elegiste PC1 o PC2 correctamente y revisa cualquier comando que modifique archivos, servicios o configuraciones.

Ayuda con comandos

El botón 📋 COMANDOS muestra comandos frecuentes y permite copiarlos. El botón 💻 CIBERCODE abre el entorno especializado para crear aplicaciones.

🎯 Modo /goal

Usa /goal cuando quieras que AGY convierta una meta grande en pasos. Explica el resultado que buscas, revisa el plan y mantén el control de lo que se ejecuta.

“Quiero comprobar que PC1 y PC2 están conectados y recibir un resumen.”
